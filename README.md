# Google Forms Automation

Проект на Python для автоматизации работы с веб-формами с помощью Playwright.

Проект создавался как практическая задача по автоматизации повторяющихся действий в браузере и работе с динамическими веб-интерфейсами.

## Возможности

- автоматическое открытие веб-формы;
- работа с различными типами полей;
- загрузка данных из JSON-файлов;
- использование разных сценариев заполнения;
- проверка обязательных файлов перед запуском;
- проверка успешного выполнения сценария;
- запуск по расписанию;
- логирование основных этапов выполнения.

## Запуск проекта

Создать виртуальное окружение:

```bash
python3 -m venv venv
```

Активировать его:

```bash
source venv/bin/activate
```

Установить необходимые зависимости:

```bash
pip install playwright
playwright install
```

Запустить основной скрипт:

```bash
python bot.py
```

Также в проекте используются дополнительные сценарии запуска:

```bash
python runner.py
```

и:

```bash
python scheduler.py
```
